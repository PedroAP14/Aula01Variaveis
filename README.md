## 📖 Manual de Markdown
O arquivo `.md` (Markdown) é uma linguagem de marcação simples para formatar textos. Aqui estão os comandos principais:

### 1. Formatação de Texto
*   **Negrito:** `**texto**` -> **texto**
*   *Itálico:* `*texto*` -> *texto*
*   `Código inline:` `` `texto` `` -> `texto`

### 2. Listas
*   Use `*`, `-` ou `+` para listas não ordenadas:
    *   Item 1
    *   Item 2

### 3. Cabeçalhos
Use `#` para definir o nível do título:
# Título H1
## Título H2
### Título H3
